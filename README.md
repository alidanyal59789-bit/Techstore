# TechStore

A modern responsive e-commerce product catalog built as a Front-End Development Internship project.

## Features
- Dynamic product catalog
- Product search
- Category filtering
- Price filtering
- Product sorting
- Shopping cart
- Product details modal
- Dark/Light mode
- LocalStorage persistence
- Fully responsive design

## Tech Stack
- React.js
- JavaScript
- Tailwind CSS
- Vite

## Run Locally
npm install
npm run dev
